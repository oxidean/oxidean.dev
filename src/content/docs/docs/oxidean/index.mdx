Oxidean is a **self-hostable code forge**: git hosting, pull requests,
issues, CI actions, and package registries in one product. The same
codebase runs Oxidean Cloud and installs on your own machines — there is no
feature fork between the hosted service and what you run yourself.
MIT-licensed.

On the mainline today: Smart-HTTP + SSH git hosting with commit-signature
verification, pull requests with merge controls and branch protection,
issues, CI actions on self-hosted runners, OCI/npm/generic package
registries, Git LFS, releases, forks, repository mirroring (push, pull, and
two-way), organizations and collaborators, notifications and webhooks,
search and explore, OIDC / WorkOS SSO, an admin console with a first-run
setup wizard, and Postgres / MySQL / SQLite backends — see
[what's shipped](https://github.com/oxidean/oxidean#readme) and
[ROADMAP.md](https://github.com/oxidean/oxidean/blob/main/ROADMAP.md) for
the rest of the distance to forge parity.
