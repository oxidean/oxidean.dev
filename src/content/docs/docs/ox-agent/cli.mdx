---
title: Ox-Agent CLI
description: "The ox-agent command surface: work items, runs, input requests, skill maintenance, state replay, and self-update."
---

```text
ox-agent version                          Show the installed binary version
ox-agent init [--repair|--sync|--integrate]
                                          Materialize or repair .ox-agent/
ox-agent integrate                        Wire AGENTS.md + .agents/.claude links
ox-agent doctor [--fix]                   Validate the local Ox-Agent setup
ox-agent start <title>                    Create a work item
ox-agent status [work-item]               List or inspect work items
ox-agent transition <wi> <state>          Move along a legal lifecycle edge
ox-agent advance <wi>                     Advance to the next profile stage
ox-agent archive|unblock <wi>             Terminal archive / clear a blocker
ox-agent run <wi>|pending                 Dispatch stage skills; list awaiting
                                          output
ox-agent run collect <run-id>             Validate and apply a run's output
ox-agent review <wi> / ship <wi>          Pipeline shortcuts
ox-agent input request|list|respond|wait|cancel
                                          Durable human-input requests
ox-agent discuss open|list|show|add|summarize|close
                                          Hash-chained discussion threads
ox-agent events [work-item]               Journal viewer
ox-agent state replay|explain             Fold or narrate the event journal
ox-agent context index|compile            Context index and packets
ox-agent skills list|check|update         Inspect and repair the skill set
ox-agent skills install|uninstall         Remote skills pinned to a commit SHA
ox-agent eval <skill> [--emit]            Score skill eval cases
ox-agent update [--check|--version v|--binary-only]
                                          Self-update binary (+ .ox-agent assets)
ox-agent completion <shell>               Shell completion script
ox-agent uninstall --yes                  Remove the binary
```

`run` dispatches the stage-mapped skill through a configured harness
adapter. `manual` prints packet and output paths for any agent,
`spawn-cli` executes a command template, and `webhook` POSTs the packet to
an HTTP(S) endpoint. `run collect` is the contract boundary: output must
match the skill's `schemas/output.schema.json` or the run is marked
failed, and the recorded `next_action` (`advance_stage`, `retry`,
`escalate`, `await_input`, `complete`) decides what happens next.
