A taste of v0:

```text title="surface.oxl"
struct Point { x: int, y: int }

fn fail(b: bool) -> [int, err] {
    if b { return 0, 1 }
    return 42, nil
}

fn main() {
    [v, err] = fail(false)
    if err != nil { return }
    println(itoa(v))

    ch := mkchan()
    scope {
        spawn send(ch, 7)
        println(itoa(recv(ch)))
    }
}
```

## The surface

- **Types** — `int float bool str cstr err chan` (`byte` lands on
  `main`), user `struct`s,
  `enum` tagged unions with `match`, slices `[]T`, function values and
  closures, and methods `fn (r T) m`.
- **Ownership** — `own T` / `ref T` / `mut T` handles with runtime borrow
  checks and compile-time move tracking; `defer` for cleanup; `extern fn`
  for C FFI.
- **Errors** — `[v, err]` returns; a dropped error is a compile error.
- **Concurrency** — `scope`/`spawn`/`go` plus `spawnBlocking` on a worker
  and blocking pool; suspend-capable functions compile to stackless state
  machines; buffered channels `mkchan(n)` and `select` multi-channel wait.
- **Generics** — `fn f[T ordered](a: T, b: T)`, monomorphized per call
  site (`interface` op constraints; `main` tightens these to `cmp.Ordered`).
- **Control flow** — `if`/`match`/`for`, `break`/`continue`, top-level
  `let` globals (process-wide state, initialized before `main`).
- **Builtins** — `print`, `itoa`, string ops, `mkbuf`/`poke*`,
  `argc`/`argv`, `readfile`/`writefile`, `exit`,
  `mkshared`/`sget`/`sset`/`scas`/`sadd`, `now`/`now_ms`/`usleep`, sqlite3
  shims, `assert`.

## The standard library

`stdlib/` ships next to the toolchain binary — pull in a package with
`import "std/<pkg>"` (`as` aliases and `.{name, ...}` selection
supported). v0.2.0 ships eight:

- **`std/strings`** — `startswith`/`endswith`/`contains`, `trim`, `split`,
  `join`, case ops
- **`std/collections`** — hash maps (`map_new`/`map_set`/`map_get`/
  `map_has`/`map_del`) over an FNV hasher
- **`std/json`** — JSON values (`jobj`/`jarr`/`jstr`/…) plus parse and
  render
- **`std/http`** — socket + HTTP helpers (`listen`/`accept`/`read`)
  behind the CRUD pilot
- **`std/os`** — `args`, `readfile`/`writefile`, `quit`
- **`std/sync`** — `mutex` (`mlock`/`munlock`) and atomic `counter`
- **`std/testing`** — `expect`/`expect_eq`/`expect_streq` assertions for
  `oxl test`
- **`std/time`** — `unix`/`unix_ms` clocks, `sleep_ms`

On `main` the library has grown well past this — `io`, `bytes`, `bufio`,
`fmt`, `strconv`, `errors`, `path`/`filepath`, `sort`/`slices`/`maps`/`cmp`,
`math`/`math/rand`, `unicode/utf8`, `flag`, `log`, `net`/`net/http`,
`encoding/{json,base64,hex,binary,csv}`, `hash`,
`crypto/{sha256,md5,hmac}`, `regexp`, and `testing` — and moves to a
`std/` tree resolved through the module system.

## Modules (on `main`)

The package/module system below is merged on `main` and ships in the next
release — the v0.2.0 binary predates it, resolving `std/` imports only.

Packages are directories of `.oxl` files that share a `package` clause;
`package main` marks an executable. A project opts into module mode by
placing an `oxl.mod` manifest at its root — the toolchain walks up from
the entry file to the nearest one; without it only `std/` imports resolve:

```text title="oxl.mod"
module github.com/me/app

oxl 0.3

require github.com/oxidean/widget v1.4.2
replace github.com/oxidean/widget => ../widget
```

Import resolution order: `std/...` (the shipped standard library) → this
module's path (resolved under the manifest's directory) → required modules
(longest path wins; `replace` directories first, then the module cache at
`$OXLMODCACHE` or `~/.oxl/mod`). Packages under `internal/` may only be
imported by code beneath the `internal` directory's parent, import cycles
are a compile error that prints the cycle chain — and an import the file
never references doesn't build either.

`oxl get <path>@<query>` fetches a module through `git` — a bare clone plus
`git archive` of the resolved commit, canonical tree bytes, never a
checkout — into a read-only content-addressed cache, upserts the `require`
line, and pins `h1:` hashes in `oxl.sum`. Every build verifies cached
modules against `oxl.sum`; queries are `@latest`, `@vX.Y.Z`, or a
branch/SHA recorded as a pseudo-version `v0.0.0-<timestamp>-<sha>`. `replace` directories
bypass cache and sums by design, and private repos work through git's own
auth. `oxl mod init|tidy|verify|list` keeps the manifest and sums in sync
so neither is edited by hand.

The canonical references live in the repository:
[`docs/semantics/`](https://github.com/oxidean/oxl/tree/main/docs/semantics)
covers ownership, concurrency, and the compiler interface, and the
[approved design spec](https://github.com/oxidean/oxl/blob/main/docs/superpowers/specs/2026-11-03-language-design.md)
is what everything traces back to.
